SNAPLITE - CAPTURAS RAPIDAS PARA WINDOWS

Esta versión usa Impr Pant para iniciar la selección de área. Tras seleccionar,
aparece una ventana con Copiar, Guardar y Cancelar. ESC cancela la selección.

No requiere instalación de .NET en el PC de destino: se publica como EXE
único y autocontenido para Windows x64.

COMO OBTENER EL EXE SIN USAR .BAT NI POWERSHELL EN TU WINDOWS LITE
1. Crea un repositorio nuevo en GitHub desde la web.
2. Sube el contenido de esta carpeta (incluida .github/workflows/build.yml).
3. En el repositorio abre Actions > Build SnapLite Windows EXE.
4. Pulsa Run workflow y espera a que termine en verde.
5. Abre la ejecución terminada, baja a Artifacts y descarga SnapLite-Windows-x64.
6. Extrae el ZIP y ejecuta SnapLite.exe.

NOTA: Impr Pant puede estar reservada por Windows o por otra utilidad. Si
SnapLite avisa que no pudo registrar la tecla, desactiva la opción de Windows
que abre Recortes al pulsar Impr Pant o cierra la aplicación que la esté usando.

El código es abierto y no incluye telemetría, publicidad ni conexiones de red.
